1. Installer selvhostet Matrix

Synapse og FjordHub-botten installeres som administrerede Docker-tjenester. Dine data gemmes i FjordHubs vedvarende datamappe. De vises ikke som apps i appoversigten.

Matrix deler FjordHubs adresse og Cloudflare Tunnel. Du skal ikke oprette et nyt domæne eller ændre tunnelens destination. Åbn FjordHub via HTTPS-adressen for at installere, hvis den ikke allerede er konfigureret i FjordHub.
Matrix-identiteten er permanent bundet til FjordHubs eksisterende domæne. Der oprettes ikke offentlige brugerkonti, og føderation er slået fra.

2. Forbind din Element X-konto

Opret en Matrix-bruger, og brug legitimationsoplysningerne til at logge ind i Element X på din iPhone. Adgangskoden vises kun én gang. Start derefter en krypteret chat med @fjordhub-bot:{{ matrix.domain or 'ditdomæne.dk' }} og skriv hjælp.

3. Kontroller push-notifikationer

Element X fra App Store bruger normalt Elements pushgateway og Apple APNs. Beskeden kan fortsat være end-to-end-krypteret. Denne opsætning hoster Matrix-serveren og botten selv, men ikke Apples eller Elements push-infrastruktur.

Aktivér notifikationer i iOS og Element X, start først en krypteret chat med botten, og tryk derefter på Send push-test ovenfor. Lås telefonen og kontroller, at beskeden kommer frem.

Botten krypterer beskeder og filer, men tillader endnu ikke manuel krypteringsnøgle-verifikation. Brug derfor ikke integrationen til hemmeligheder, før enhedsverifikation er implementeret. Push kan først bekræftes ved test på din rigtige iPhone.
