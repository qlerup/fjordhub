1. Installér Visual Studio Code

Installerer den rigtige Linux-version af VS Code i en separat Docker-container med OpenAI Codex-udvidelsen. Projektfiler, Codex-skills og indstillinger bevares på serveren ved genstart.

Den første installation downloader et større image og kan tage nogle minutter. Ingen nye domæner eller porte åbnes.

2. Åbn VS Code og log ind på Codex

Åbn det fulde skrivebord i browseren. Vælg Codex i VS Code, og log ind med din ChatGPT-konto. Alle fremtidige kodeopgaver kan så arbejde med projekter under /workspaces.

Åbn Visual Studio Code →

Skills fra din PC skal importeres én gang til /config/fjordcode-home/.codex/skills. Det samme projektlager deles med den tidligere Codex-worker. VS Code-udvidelsens login foretages i selve editoren.
